# Banners Folder

Thư mục này dành cho banner local của homepage.

Định dạng khuyến nghị:
- `banner-01.jpg`
- `banner-02.jpg`
- `banner-03.jpg`
- `banner-04.jpg`

Kích thước khuyến nghị: `1400x500` hoặc tỉ lệ gần `16:6`.

Nếu ảnh từ internet lỗi tải, app sẽ fallback nền trống và bạn có thể thay bằng ảnh local trong folder này.
